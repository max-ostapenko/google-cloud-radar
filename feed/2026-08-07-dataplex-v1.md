# Dataplex adds ChangeRequest comments and EntryLinkType events

**Date:** 2026-08-07  
**API:** `dataplex.v1`  
**Impact:** Low  

## Summary

Dataplex now supports reviewer comments on ChangeRequests and introduces a new event schema for tracking EntryLinkType lifecycle changes.

## Details

The GoogleCloudDataplexV1ApproveChangeRequestRequest schema now includes an optional 'comment' field (up to 1024 characters) for providing context during approval. Correspondingly, the GoogleCloudDataplexV1ChangeRequest resource gains an output-only 'reviewerComment' field to display these notes. Additionally, a new GoogleCloudDataplexV1EntryLinkTypeEvent schema has been added to support logging for EntryLinkType creation, updates, and deletions, facilitating better audit trails for metadata changes.
