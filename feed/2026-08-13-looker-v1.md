# Looker adds ESA migration support to ExportMetadata

**Date:** 2026-08-13  
**API:** `looker.v1`  
**Impact:** Low  

## Summary

Looker's ExportMetadata schema now includes a field for specifying source BigQuery datasets during Elite System Activity (ESA) migrations.

## Details

A new field `esaSourceDatasetId` has been added to the `ExportMetadata` schema. This field accepts a string formatted as `project_id:dataset_id` and is specifically intended for O2C Elite System Activity (ESA) direct dataset migrations. This allows for more granular control over the source data during specific migration workflows.
